# Additional review rubrics

Tau Ceti's live rubric files remain required and primary. This registry adds
only three angles that are not cleanly owned by one of them.

| rubric id | question |
|---|---|
| `ut-dependency-readiness` | Are the required mathematical and API prerequisites merged and stable, and does this slice avoid making provisional downstream work look final? |
| `ut-consumer-contract` | Can a small downstream consumer use the intended public equations without unfolding private constructions or relying on accidental definitional equality? |
| `ut-structural-boundary` | Is the change's own diff coherent, with the right module owner and import direction, independently of any stacked GitHub-visible prerequisites? |
